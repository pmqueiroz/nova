Configuration

Config file location, behavior, and full settings reference.

Edit on GitHub

#Location

Nova stores settings at settings.toml under your OS config directory:

~/Library/Application Support/nova/settings.toml
%APPDATA%\nova\settings.toml
~/.config/nova/settings.toml

Internally, this is dirs::config_dir().join("nova").join("settings.toml").

#File Lifecycle

  • If settings.toml does not exist, Nova writes an embedded default config.
  • If settings.toml exists but TOML parsing fails, Nova overwrites it with defaults.
A malformed edit resets everything

This means a malformed edit can be “repaired” by reset-to-default (but you may lose changes).

#Defaults

Nova ships embedded defaults (slightly different on macOS).

Non-macOS default excerpt:

toml
[general]
editor = "nano"
bell = "none"
check-updates = true

[theme.font]
size = 16
family = "FiraCode Nerd Font"

[theme.colors]
background = "#0D0D0D"
foreground = "#E5E5E5"
accent = "#82BAFF"
foreground-muted = "#666666"
border = "#FFFFFF12"
cursor = "#82BAFF"

[theme.cursor]
style = "underline"
blink = false

[keybindings]
new-tab = "ctrl+t"
close-tab = "ctrl+w"
next-tab = "ctrl+tab"
prev-tab = "ctrl+shift+tab"
paste = "ctrl+v"
copy = "ctrl+shift+c"
open-palette = "ctrl+p"
ask-ai = "ctrl+k"
settings = "ctrl+,"

[ai]
provider = "anthropic"
model = "claude-haiku-4-5-20251001"
api_key = ""

#Reference

#[general]

  • editor (string): External editor command.
  • bell (string): One of none, audio, blink. PowerShell’s own error ding (PSReadLine) follows this too: it stays audible only with audio. Changes apply to shells started after Nova restarts.
  • shells (array of strings, optional): If set and non-empty, Nova uses this list instead of auto-detect.
  • initial-command (string, optional): Program each new pane runs instead of the shell, launched directly (not through a shell), so shell built-ins and aliases such as PowerShell’s ls do not work. If it cannot be started, the pane shows why instead of a blank screen.
  • wait-after-command (bool): Wait for a key after the initial command exits.
  • window-controls (string): One of traffic-lights or system.
  • scrollback (integer, optional): Maximum scrollback lines per pane. Defaults to 10000.
  • check-updates (bool): Check GitHub for a newer release on startup and once a day. Defaults to true. Turn it off if a package manager keeps Nova up to date. Also in Settings → About.

Example:

toml
[general]
editor = "code -w"
bell = "none"
shells = ["zsh", "bash"]
window-controls = "system"

#[theme]

  • timestamps (bool, default false): show the HH:MM each command ran next to its block.

#[theme.font]

  • size (number)
  • family (string)

Example:

toml
[theme.font]
size = 15
family = "FiraCode Nerd Font"

#[theme.colors]

All values are hex strings.

  • #RRGGBB is supported.
  • #RRGGBBAA is supported (alpha channel).

Keys:

  • background
  • foreground
  • accent (the settings sheet offers Blue #82BAFF, Mint #65DFAF, Amber #FCBE62, Rose #FC899D)
  • foreground-muted
  • border
  • cursor

Example:

toml
[theme.colors]
background = "#0D0D0D"
foreground = "#E5E5E5"
accent = "#82BAFF"
foreground-muted = "#666666"
border = "#FFFFFF12"
cursor = "#82BAFF"

[theme.cursor]
style = "underline"
blink = true

[ai]
provider = "anthropic"
model = "claude-haiku-4-5-20251001"
api_key = ""

#[theme.cursor]

  • style (string): Cursor shape. One of block, beam, underline.
  • blink (bool): Whether the cursor blinks.

Example:

toml
[theme.cursor]
style = "underline"
blink = true

#[keybindings]

See Keybindings for syntax and examples.

Keys:

  • new-tab
  • close-tab
  • next-tab
  • prev-tab
  • paste
  • copy
  • open-palette
  • ask-ai
  • settings

#[ai]

See AI for behavior and troubleshooting.

  • provider (string): anthropic or openai
  • model (string)
  • api_key (string)
  • base_url (string, optional): Override API base URL (useful for proxies).

Example:

toml
[ai]
provider = "openai"
model = "gpt-4.1-mini"
api_key = "..."
base_url = "https://api.openai.com/v1/"
