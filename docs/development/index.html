Development

Building Nova, working on the codebase, and building the docs site.

Edit on GitHub

#Build Nova

Nova uses Rust (stable, edition 2024).

bash
git clone https://github.com/pmqueiroz/nova.git
cd nova
cargo build --release

Binary output:

text
./target/release/nova

For local iteration:

bash
cargo run

On Windows, fetch the bundled ConPTY once so dev builds pass mouse reporting through like release builds (it copies conpty.dll and OpenConsole.exe into target/debug and target/release):

powershell
./packaging/conpty/fetch.ps1

#Code Map

High-level ownership:

  • src/core/: config, grid model, ANSI/VTE state, AI client
  • src/sys/: PTY bridge, platform I/O, terminal parser
  • src/ui/: iced application, components, theme

#Build The Docs Site

The site and docs live in docs/ and are built with Astro. Pages are Markdown in docs/src/content/docs/.

From the repo root:

bash
cd docs
bun install
bun run dev

Build output goes to docs/dist:

bash
cd docs
bun run build

#CI Notes

The main CI enforces formatting and linting.

Before opening a PR:

bash
cargo fmt
cargo clippy
cargo build
