Troubleshooting

Common problems and fixes.

Edit on GitHub

#macOS: “Nova is damaged and can’t be opened”

Nova is not notarized. macOS Gatekeeper may block it.

If you installed the app bundle, you can clear the quarantine attribute:

bash
xattr -cr /Applications/Nova.app

#Settings Keep Resetting

Nova overwrites settings.toml with defaults if it fails to parse as TOML.

If your settings keep resetting:

  • Validate your TOML syntax (missing quotes, stray commas, etc.)
  • Keep a backup copy while editing

#nova ask Must Be Run Inside Nova

nova ask is an integration command that signals the running Nova app via OSC.

If you run it in another terminal, you’ll get:

text
error: 'nova ask' must be run inside Nova terminal

Run it inside Nova, or use the in-app command palette action.

#Pagers (git log, man) Stay Inside a Block

Nova shows a program fullscreen when it switches to the terminal’s alternate screen, or when it turns on bracketed paste (interactive apps such as Claude Code, REPLs and nested shells over ssh). An app that does bracketed paste stays fullscreen until it exits. less skips that switch when its options contain X, and Git runs it with LESS=FRX when LESS is unset.

Nova therefore starts its shells with LESS=FR (pager output that fits on one screen still prints inline and exits). If you set LESS yourself, Nova leaves it alone: drop the X flag from it to get fullscreen pagers.

In PowerShell, help (and its alias man) normally pipes through Windows’ more, which never goes fullscreen and waits for a key after every page. Nova’s PowerShell session replaces help: it pages through less when one is on PATH, otherwise it prints the whole topic into the block, which you can scroll.

While a program is fullscreen, the mouse wheel scrolls it: Nova sends arrow keys, or wheel events if the program asked for mouse reporting.

On Windows, Nova only learns that a program asked for mouse reporting through the conpty.dll and OpenConsole.exe shipped next to nova.exe. The console built into Windows drops those requests, so without them the wheel sends arrow keys everywhere and apps such as Claude Code warn “Scroll wheel is sending arrow keys”. The installer, the portable ZIP and Scoop include both files; a cargo install build does not.

#AI Errors

  • Missing key: set [ai].api_key.
  • Wrong model/provider: ensure model name matches the selected provider.
  • Proxy issues: verify [ai].base_url is correct and reachable.

#Updates Fail

  • Permission denied replacing nova.exe, Nova.app or the AppImage: Nova writes next to the existing file, so its folder must be writable by you. Move it somewhere you own, or update with the method you installed with.
  • Windows installer: a per-machine install (under Program Files) asks for admin rights (UAC) when the update runs. The installer closes every open Nova window.
  • apt / dnf / AUR / Homebrew: the update runs in a new tab and may ask for your sudo password there. If it fails, the tab shows the package manager’s error; re-run nova update --install or the shown command yourself.
  • “checksum mismatch”: the download was corrupted or tampered with, so nothing was replaced. Try again later.
  • Updates are cached in your user cache folder under nova/updates/ and removed once you run that version.
