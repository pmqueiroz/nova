AI powered terminal

Nova is a GPU-accelerated terminal written in Rust. Each command and its output land in blocks where you can select, search and copy, so the line you need never gets lost in the scroll.

Features

Built around the block.

Scrollback is a wall of text. Nova splits it at every prompt, so each command, its output and its exit status stay together.

01Command blocks

Select, search and copy one command at a time.

Each command and its output is a card. Click to select it, copy just the command or just the output, or search inside it. Failed commands are marked in red with their exit code.

  • Full-screen apps like vim and htop take over the pane until they exit.
  • Optional timestamps show when each command ran.

02Ask AI

Fix the last failed command without leaving the prompt.

Describe what you want in plain words and get a command back. Ask it to fix the command that just failed, or explain the output you're looking at. Replies that contain a command get a Run button.

  • Works with Anthropic or OpenAI, using your own API key.
  • Off until you set a key. Nothing is sent otherwise.
